# Quan Tran — Mechanical Engineering Portfolio

Recruiter-facing portfolio for Quan Tran, a Mechanical Engineering student at the University of Cincinnati.

## GitHub Pages

The repository deploys automatically to [tquann207.github.io](https://tquann207.github.io) after each push to `main`.

## Local development

```bash
npm ci
npm run dev
```

## Static build

```bash
npm run build:github
```
