# Project media

Create one folder per project and add only real, approved assets: `smart-delivery-box/`, `nvh-test-rig/`, `hybrid-health-supply-network/`, `f-race/`, `self-balancing/`, and `micromouse/`.

Use WebP or AVIF for photographs/renders, SVG for diagrams, and MP4/WebM for short videos. Add descriptive filenames such as `cad-enclosure-01.webp`, then update `content/site.ts`.
